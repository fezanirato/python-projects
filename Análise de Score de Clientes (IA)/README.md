## Sobre o Projeto
Este projeto utiliza Python e Machine Learning para analisar o score de clientes de um banco.

A partir de uma base com milhares de clientes, o objetivo é prever se um cliente é um bom pagador ou apresenta risco, auxiliando na tomada de decisões como concessão de crédito e empréstimos.

---

## Objetivo
Desenvolver modelos de classificação e identificar qual apresenta melhor desempenho na previsão do score dos clientes.

---

## Etapas do Projeto
- Importação da base de dados  
- Tratamento de dados (valores nulos e inconsistências)  
- Seleção das variáveis (features)  
- Treinamento de modelos de classificação  
- Avaliação e comparação dos modelos - Árvore de Decisão e KNeighborhood  
- Análise das variáveis mais importantes  

---

## Tecnologias
- Python  
- Pandas  
- Scikit-learn  
- NumPy  

---

## Resultado
O modelo utilizado para prever o comportamento dos clientes foi o modelo Árvore de Decisão, foi o modelo que obteve maior acurácia ajudando o banco a reduzir riscos e decidir quais são os melhores pagadores para concessão de créditos.

---

## Observação
Modelos preditivos não atingem 100% de acurácia, mas podem gerar resultados confiáveis para apoio à decisão.
